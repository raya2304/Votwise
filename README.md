# VoltWise - Electricity Bill Calculator

VoltWise is a modern and responsive electricity bill calculator website designed to help users estimate their monthly electricity expenses and understand their energy consumption.

The website provides a simple interface where users can enter their electricity usage and instantly view an estimated bill based on different consumption slabs.

## Features

* Electricity bill calculator
* Slab-based unit calculation
* Monthly consumption input
* Billing period selection
* Estimated energy charge
* Service charge calculation
* Total bill estimation
* Daily electricity usage calculation
* Consumption level indicator
* Potential savings estimate
* Appliance energy usage guide
* Energy-saving tips
* Responsive design
* Input validation
* Interactive user interface

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

## How It Works

1. Enter your monthly electricity consumption in units.
2. Select the billing period.
3. Click **Calculate My Bill**.
4. The website calculates the energy charge according to the defined tariff slabs.
5. The estimated total bill, daily usage and potential savings are displayed.
6. The consumption indicator shows whether the usage is low, moderate, high or very high.

## Tariff Structure

The project uses an illustrative slab-based calculation:

| Units     |       Rate |
| --------- | ---------: |
| 0 - 100   | ₹2.00/unit |
| 101 - 200 | ₹3.50/unit |
| 201 - 400 | ₹5.00/unit |
| 401+      | ₹6.50/unit |

A fixed service charge is also included in the example calculation.

> Note: The tariff values used in this project are for demonstration purposes. Actual electricity charges may vary depending on the electricity provider, location, tariff category and billing rules.
